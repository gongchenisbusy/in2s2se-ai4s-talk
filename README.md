# AI 辅助五层 Janus In₂S₂Se：HTML 研究计划汇报

打开 [index.html](index.html) 即可在浏览器中放映。整套共 9 页，按**研究背景 → 体系选择 → 研究路径 → 研究目标**组织，适合约 10 分钟讲述。全部脚本、样式、矢量图和文献图都保存在此目录，文件可离线打开。

## 操作

- 左右方向键、空格：翻页
- F：全屏
- S：打开带当前页、下一页、讲者备注和计时器的讲者视图
- 在讲者视图的“逐字稿”卡片点击“编辑讲稿”，直接改写当前页；输入时自动保存在当前浏览器，点击“完成编辑”返回阅读模式
- “恢复原稿”可撤销当前页的本地修改；“导出”与“导入”可用 JSON 文件将修改转移到其他设备
- N：在观众窗口临时查看讲者备注
- O：九页总览
- 文献局部图可点击打开原尺寸

每页的讲述提示已写在 HTML 的 notes 元素中，观众视图不显示。网页中的讲稿修改保存在浏览器本地，不会自动写回 GitHub，也不会自动同步到其他设备；清除网站数据可能删除这些修改，建议导出备份。图中文字中的“理论预测”“示意”“文献先例”分别标明证据性质；研究阶段只写任务和验证门槛，不含研究期限或月份。

## 文件

- index.html：可直接演示的 HTML 幻灯片
- style.css、assets/：本地 CSS 和键盘/讲者视图运行脚本
- media/figures/：9 张莫兰迪配色的逐页 SVG
- media/literature/：4 篇文献中的 5 张局部图；每张图的出处在相应页面注明
- preview/：1920 × 1080 的逐页渲染检查图和[九页总览](preview/contact.png)

## 依据

研究文献和图片出处标注在对应幻灯片中。页面中的文献图用于注明来源的研究汇报。若再次公开分发，请按原出版版本核对图像使用条款。
